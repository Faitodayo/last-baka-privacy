Made By Last Baka · Chrome Extension

Privacy Policy

Delta Force Garena Code Hub

Effective date: November 12, 2026

1. Overview

Made By Last Baka is an independent browser extension that helps users organize and redeem Delta Force Garena gift codes, check configured code sources, and optionally identify possible codes in Facebook posts visible to the user. It is not affiliated with or endorsed by Garena, Delta Force, Google, or Meta.

2. Information processed

  • Gift codes entered by users and codes found in configured public sources.
  • Code processing status, redemption results, and saved queue progress.
  • Visible text from Facebook pages and groups when the user requests a scan, for the purpose of finding possible redemption codes.
  • Information needed to identify eligible open tabs for requested features.

The extension does not require users to provide their Facebook or Google passwords to the extension.

3. Purposes and functionality

Information is used to identify and organize potential gift codes, remove duplicates, save redemption progress, and update the local code catalog. When a user starts redemption, codes are submitted to the Garena redemption website. The extension may fetch public code information from Google Sheets and configured websites while Chrome is running.

4. Local storage and sharing

Code lists, statuses, progress, and related settings are stored using Chrome extension local storage. The extension is not designed to sell personal data or send collected Facebook post text to an independent analytics server. Codes submitted for redemption are processed by Garena under Garena's own terms and privacy practices. Requests to third-party code sources necessarily contact those websites.

5. Facebook group content

Facebook scanning is limited to content accessible to the signed-in user and loaded in their browser. The extension does not bypass access controls or request access to private groups the user cannot view. Extracted candidate codes may be saved locally along with source references. Users should review candidate codes before redemption.

6. Data retention and user choices

Locally stored code information remains until the user clears the extension's data or removes the extension, subject to browser behavior. Users can stop processing, choose whether to scan Facebook content, and choose which codes to submit. Uninstalling the extension removes its access to websites.

7. Security

The extension uses the browser's permission model. No system can guarantee absolute security. Users should only install releases from sources they trust and review the permissions requested.

8. Third-party services

Supported services may include redeem.df.garena.sg, docs.google.com, download.com.vn, codelmh.com, and Facebook. Their separate privacy policies apply to their services.

9. Updates

This policy may be updated when the extension's behavior or data practices change. Material changes should be reflected in this page and in the Chrome Web Store privacy disclosures.

10. Contact

For privacy requests and support, contact the developer using the contact information provided on the Chrome Web Store listing for Made By Last Baka. Developer: add a working contact address before publishing this policy.

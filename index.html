Privacy Policy

Made By Last Baka · Delta Force Garena Code Hub · Version 6.5.0

Last updated: November 12, 2026

1. Extension and scope

Made By Last Baka v6.5 is an independent browser extension for finding, organizing and submitting Delta Force Garena redemption codes. It is not affiliated with Garena, Delta Force, Meta, Google or the websites listed below. This policy describes the behavior of version 6.5.0.

2. Data accessed and collected

The extension processes gift codes typed or pasted by the user; code queues, delays, success/failure counts, checkpoints and processing results; potential gift codes extracted from publicly accessible web code listings and a configured Google Sheets document; and candidate code strings and source post links from Facebook pages or groups that the user is authorized to view. To perform a user-requested Facebook scan, the extension reads the visible text of up to 250 loaded Facebook posts (or visible page text when post elements are unavailable), plus available post links. It inspects open tab addresses to locate eligible Facebook tabs. It does not need Facebook passwords, Google passwords, payment details or health data.

3. When and why processing occurs

When you open the Garena redemption page, the extension displays its dashboard. When you type codes or start redemption, it processes the codes and tracks results. When you request a Facebook scan, it reads already-loaded visible content in an accessible Facebook tab and extracts strings resembling codes; this feature does not automatically scan every group. When Chrome is running, the extension schedules requests to configured public code pages approximately every six hours and to the configured Google Sheets document approximately every hour. Manual refresh is also available. Newly found codes are not automatically submitted to Garena.

4. Local storage, retention and deletion

The extension uses chrome.storage.local on your device to store code lists, code source labels and links, first-seen timestamps, unverified status, redemption results, input values, delay preferences, batch progress and last-check times/errors. Data may persist between browser sessions without a fixed automatic expiry. The local code catalog may hold thousands of entries. You can delete the stored data by using Chrome’s extension site-data controls or removing the extension and its data. Removing the extension does not delete information already submitted to Garena or information independently held by third-party sites.

5. Data transmission and all recipients

Garena (redeem.df.garena.sg): when you choose to redeem codes, the browser submits those codes to Garena for validation and redemption. Garena may process the submission and account/session information according to its own privacy policy. Google (docs.google.com): the extension requests a configured public Google Sheets CSV feed to obtain code listings; the request exposes normal network metadata such as IP address and browser request headers to Google, but the extension does not intentionally send locally stored codes or Facebook post text to Google. Download.com.vn and CodeLMH (codelmh.com): the extension requests their public pages for code listings, exposing normal request metadata to each site; it does not intentionally upload your saved code list or Facebook text. Meta/Facebook: the extension reads visible content from Facebook pages already open in your browser when you request a scan; the extension does not intentionally transmit extracted Facebook content or stored code lists to Meta through a separate extension endpoint. Chrome/Google browser services: the extension uses Chrome local storage and extension APIs; Chrome’s own operation and synchronization settings are governed by Google’s policies. No separate developer-owned analytics, advertising, cloud storage, or code-collection endpoint is implemented in the reviewed v6.5 package. The developer does not sell user data. This description does not override data processing performed independently by the websites you visit.

6. Facebook groups, including private groups

A Facebook scan is user-initiated and limited to content already available to the signed-in browser session. It does not bypass group membership rules or access restrictions. The scanner looks for code-like strings near relevant text and stores candidate codes and source post URLs locally; false positives are possible. It does not intentionally store full Facebook post text or profile details. If a code or source URL contains personal information, that information could be retained as part of the candidate code entry.

7. Permissions

activeTab and scripting support user-requested interaction with supported tabs; tabs helps find open eligible Facebook tabs and toggle the Garena dashboard; storage saves local codes and progress; alarms schedules code-source checks. Host permissions are requested for redeem.df.garena.sg, docs.google.com, download.com.vn, codelmh.com, and Facebook domains (www.facebook.com, web.facebook.com, m.facebook.com). The extension’s packaged scripts execute in supported pages. These permissions should be reviewed against the published extension version.

8. Security and choices

The extension does not ask for your passwords or intentionally extract authentication cookies. Public-source network requests in the reviewed code use credentials: omit. Users can decline Facebook scans, avoid starting redemption, remove codes from the input, or uninstall the extension. Do not enter sensitive information into code fields. No transmission or storage method is guaranteed perfectly secure.

9. Policy changes

This policy applies to version 6.5.0 as reviewed on November 12, 2026. The policy may change when extension features, permissions, recipients or data practices change. Material changes will be reflected in the published policy and, where required, in extension disclosures.

1. Extension, developer and scope

Delta Force Garena Code Redeemer (version 6.5.1) is an independent browser extension created by Made By Last Baka. Its purpose is to help Delta Force Garena players collect, import, organize and submit gift codes through the official Garena redemption website. It is not affiliated with or endorsed by Garena, Delta Force, Google, Meta, PayPal or the owners of external source websites.

This policy describes how the extension accesses and processes information, what is stored on your device, when external websites receive network requests, and the choices available to you.

2. Information processed

Depending on which features you use, the extension may process: (a) gift codes you enter, paste or import; (b) code lists, processing options, delays, progress, timestamps and redemption outcomes; (c) code-like text, URLs and source information from configured public gift-code websites and Google Sheets; (d) visible page or post content already available in an open Facebook tab when you explicitly request a scan; (e) URLs of approved personal sources and user-submitted source proposals; (f) images you select for on-device code extraction; and (g) your chosen interface language and Garena region.

The Garena region you select is an application preference and is not GPS tracking. The extension uses tab URLs and titles where needed to identify the official Garena page, an eligible open Facebook tab or a source you choose to save. It is not designed to record a general browsing history or log arbitrary keystrokes.

Please do not enter passwords, one-time passwords (OTPs), authentication tokens, financial account details or private personal information into gift-code fields.

3. Redemption and official Garena website

When you choose to start redemption, the extension enters codes into the official Garena redemption site and reads the results presented by that site. Garena receives the submitted codes and may process account, session and request information under its own terms and privacy policy. The extension does not bypass CAPTCHA, OTP or login checks. If no response can be confirmed, the extension may label a result as unknown; this does not establish whether Garena accepted a code.

The extension may retain the current list and local progress between sessions. Keeping its dashboard hidden is not the same as running independently after you close or suspend the Garena tab.

4. Code Hub, public sources, Facebook and optional checks

Code Hub can retrieve code-like strings from configured public Google Sheets CSV feeds and supported public websites. Network requests expose ordinary request metadata, such as your IP address and browser request headers, to each destination. Requests for public source pages are configured without browser credentials where implemented.

A Facebook scan happens when the user requests it. It reads text already accessible in the chosen open Facebook tab, including content from groups you can already access; it does not bypass private-group membership or other access restrictions. The scanner extracts candidate codes and associated source URLs for local use. It does not intentionally save full Facebook post bodies or profile data as separate records, although a saved code or source URL can itself contain personal information.

Website discovery, source checks, public-sheet synchronization and automatic refresh depend on the relevant user settings and available site permissions. Automatic refresh requires the user to enable it. You can manage or disable optional sources and related features. Finding a candidate code does not mean the code is valid or that it will be automatically submitted to Garena.

5. File import, OCR and exports

Users can paste code lists or import TXT and CSV files, and select or drag in PNG, JPG/JPEG, WEBP or BMP images to attempt local text recognition. The packaged OCR tool processes selected images within the browser and does not send them to a dedicated external OCR service. Detection accuracy depends on the image and browser capabilities; users should review extracted strings before redemption.

Users may export code lists and locally recorded results into TXT or UTF-8 CSV files, copy them to the clipboard, or back up and re-import their own source lists. These exports are initiated by the user. If you upload an exported file to Excel Online, Google Sheets or another service yourself, that service's privacy terms apply.

6. Local storage and retention

The extension uses chrome.storage.local to keep interface preferences, selected Garena region, gift-code input lists, source links, approved-source settings, optional-feature consents, code-catalog records, timestamps, recorded results, prior attempts and processing state. Personal source lists and locally collected candidates are stored on your device. Records can persist between browsing sessions and may not have a fixed automatic expiration date.

You can remove codes using the extension's available controls, disable or delete saved sources, or remove the extension and its local data through Chrome. Uninstalling does not delete information already processed by Garena or external websites, or exported files that you saved elsewhere.

7. External destinations and data sharing

Garena: codes are submitted to redeem.df.garena.sg when redemption is initiated. Public source providers: requests may be made to docs.google.com, download.com.vn, codelmh.com and other enabled, approved HTTPS sources, depending on the user's chosen features. Such providers receive ordinary web-request metadata. Meta/Facebook: the extension reads content available in the selected Facebook browser tab during a requested scan; it does not intentionally send extracted content to a developer-operated collection endpoint.

Support: the Feedback & Support feature prepares a message addressed to giang8lx2015@gmail.com using your email application or Gmail compose page. A draft is not sent until you choose to send it. When you do send it, the developer and your email service receive the message and any sender details you include. Please do not send passwords, OTPs or other sensitive information. Donations: the donation panel displays local payment QR/account information and can open PayPal.me/lastbaka. Payment details and transactions are handled by your payment provider, not collected by a payment form inside the extension.

There is no separate developer-operated analytics, advertising or general-purpose user-data upload endpoint in the reviewed extension package. This statement is about the reviewed v6.5.1 package and does not prevent ordinary data collection performed by websites, browser providers, email services or payment services that you independently use. The developer does not sell user data.

8. Permissions and user controls

storage saves settings and code records locally; tabs helps locate the official redemption tab, user-selected sources and eligible Facebook tabs; scripting can initialize the dashboard on the Garena redemption page; and alarms schedules optional refresh checks. Host access includes the official Garena page and configured source websites, including certain Facebook domains and public-site providers. The extension may request additional HTTPS host access for a website you choose to add or enable. Review these permissions in Chrome and enable only sources you trust.

The extension contains content scripts for supported Garena and Facebook pages. Website-access permissions can allow extensions to read content at the relevant websites. Permission explanations in the extension are intended to help you make informed choices; they are not a substitute for Chrome's own permission controls.

9. Security and limitations

The extension does not ask you to type your Garena or Google password into a separate extension login form. It is not designed to extract authentication cookies or send them to the developer. Do not use untrusted source lists or import files without reviewing their contents. No local storage, network transport, source site or browser extension can be guaranteed perfectly secure.

Gift-code and OCR candidates may be inaccurate; verify code strings and results before acting on them.

10. Children, changes and contact

The extension is intended for users who can lawfully access the relevant game and services. It is not designed specifically to collect children's personal information. We may update this policy if features, recipients, permissions or storage practices change. Significant changes should be reflected in the extension's store disclosures.
